# Rose Way Billing — Releases

Auto-update feed for **Rose Way Billing** (internal desktop app for The Rose Way Logistics Co., Ltd.).

This repo holds only built installers, published as GitHub Releases. No source code is published here —
the app's source lives in a separate private repository. `electron-updater` in the app checks this repo's
releases to notify users of new versions.


Latest published version: v1.0.65
